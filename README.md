# Proyecto Web Java EE

Aplicación web desarrollada en Java EE utilizando JSP, HTML, CSS y JPA, como parte del curso de Java Web de TodoCode.

## Tecnologías utilizadas
- Java EE (JSP y Servlets)
- JPA (Jakarta Persistence API)
- HTML5 y CSS3
- PSQL
- Apache Tomcat
- Maven

## Contenidos aprendidos
- Creación de aplicaciones web con arquitectura MVC
- Uso de JSP y Servlets para la capa de presentación
- Conexión con bases de datos mediante JPA y persistencia de entidades
- Configuración y despliegue de proyectos en Apache Tomcat
- Integración de frontend (HTML y CSS) con la lógica en Java
- Organización de proyectos con Maven
